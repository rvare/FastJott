# FastJott

A simple utility for working with notes.txt files written in Rust.

(If you don't know what a notes.txt file is, check my article: [notes.txt]())

## Features

- Easily write notes by simply invoking the program.
- Find specific notes with by using a string.
- Archive your notes with a simple command.

## Getting Help

If you have it installed on your system, simply use `-h`/`--help` to get help info.
